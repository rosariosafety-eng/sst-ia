SST IA V3.1 — EPP casco + evidencia manual

CAMBIOS
- El modelo especializado Hardhat / NO-Hardhat se mantiene.
- Confianza predeterminada: 40%. Recomendado 40–50%.
- Capturar evidencia ahora abre un formulario para registrar el hallazgo.
- Una captura manual guardada se incorpora al informe aunque la IA no la haya detectado.
- El formulario permite editar título, sector, clasificación, observación, normativa y acción.
- Los hallazgos automáticos mantienen su confianza IA; los manuales no muestran confianza.

ACLARACIÓN
Capturar una foto por sí sola no equivale a un hallazgo: en V3.1 la captura abre inmediatamente el formulario. Al tocar Guardar hallazgo, queda registrada y luego aparece en Generar informe.

PARA CASCOS LEJANOS
- 40–50% para uso habitual.
- 30–40% si el casco ocupa pocos píxeles.
- Acercarse mejora mucho el resultado.
- 70–80% puede generar falsos negativos en escenas amplias.
