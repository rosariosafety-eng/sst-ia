SST IA V4.2 — Evaluación seleccionable + ergonomía

- Selector de tarea con perfiles sugeridos.
- Lista de riesgos a evaluar: todos, ninguno o combinación libre.
- Las detecciones visuales de EPP solo se dibujan/alertan si ese EPP fue seleccionado.
- Screening ergonómico con MoveNet: flexión de tronco, postura agachada/rodillas muy flexionadas y brazos elevados.
- Ergonomía: Resolución SRT 886/2015 + Resolución MTEySS 295/2003 Anexo I.
- El screening visual no sustituye evaluación ergonómica formal; no mide peso, fuerza, frecuencia ni duración.
- Electricidad, incendio, máquinas, almacenamiento, químicos y espacios confinados siguen como inspección guiada hasta incorporar detectores específicos.
